# CitroenC4Monitor

Windows-приложение для пассивного мониторинга CAN автомобиля Citroën C4 II (B7).

## Статус

Это стартовый инструмент для захвата и маркировки CAN-кадров. Он **не декодирует** параметры автомобиля и не отправляет CAN-команды. Используйте только режим listen-only.

## Установка

```powershell
py -m venv .venv
.\\.venv\\Scripts\\Activate.ps1
pip install -r requirements.txt
py main.py
```

## Подключение

Укажите COM-порт адаптера WeAct (например COM3), скорость последовательного порта 115200 и скорость CAN, подтверждённую для выбранной шины. Начинайте только с пассивного прослушивания. Настройки контактов OBD и скорости CAN должны быть проверены по электросхеме именно вашего VIN/комплектации.

## Инструкция по проверке

Подробное пошаговое руководство на русском: [docs/TESTING_GUIDE_RU.md](docs/TESTING_GUIDE_RU.md). В нём описаны подготовка адаптера, безопасное подключение, первый захват, проверка кнопок руля и панели, сверка параметров с Diagbox и критерии достоверности.

## Безопасность и ограничения

- Не подключайте адаптер к неизвестным контактам и не замыкайте линии.
- Не отправляйте кадры, не кодируйте BSI/ABS и не меняйте конфигурацию блоков.
- Один адаптер обычно слушает только один CAN-канал одновременно.
- Этот прототип разбирает классические SLCAN CAN-кадры; CAN FD и диагностические протоколы PSA требуют отдельной реализации и проверки.
- Для полного доступа к ABS, BSI и другим ECU может потребоваться совместимый PSA диагностический интерфейс и Diagbox.

## Маркировка кнопок

Сначала запишите базовый трафик, затем нажимайте по одной кнопке с паузой и ставьте метку события в приложении. Повторите каждое нажатие несколько раз. Сигнал кнопки может идти по другой CAN-сети или LIN, поэтому отсутствие изменения в текущем захвате ничего не доказывает.

## Файлы

- `capture_*.csv` — принятые кадры
- `events_*.csv` — метки действий пользователя
